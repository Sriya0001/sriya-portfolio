# Sriya Kunisetty — Engineering Portfolio Website

An elegant, modern, high-performance portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**, featuring the warm autumn / latte elegance aesthetic inspired by modern editorial portfolios.

---

## 🌟 Highlights & Features

- **Hero & Identity**: Editorial bold typography (`Outfit` & `Playfair Display`), multi-layered portrait frame, floating live metric chips (`9.37 CGPA @ Vasavi IT`, `Top 3K / 1.3L Amazon ML`, `DBS Tech Apprentice`).
- **Interactive 3D Glare Cards**: Mouse-tracking glare and perspective tilt effects for academic and competition statistics.
- **Continuous Skills Marquee**: Infinite smooth running ticker showcasing technologies, frameworks, and core CS fundamentals.
- **Expertise & Capabilities ("What I Do")**: Deep luxury cocoa aesthetic (`#442D1C`) detailing Full-Stack Architecture, AI & ML Modeling, Cloud & Distributed Systems, and Algorithmic Optimization.
- **Selected Projects & System Architecture Deep Dive**:
  - **Smart Medical Practice Management & Patient Engagement System** (Spring Boot, Angular, MySQL, JWT)
  - **Smart Student Hub** (React, Node.js, Express.js, MongoDB Atlas, Redis Rate Limiting, AWS S3 SHA-256 Pre-Signed URLs)
  - **ThrillSafari – Smart Theme Park Ride Planner** (React, Python Flask, Random Forest wait prediction, Binary Max-Heap scheduling)
  - Interactive project detail modal with architecture diagrams and telemetry.
- **Honors & Credentials**:
  - **Amazon ML Summer School 2026** (Top 3,000 out of 1.3 Lakh applicants)
  - **Flipkart GRiD 8.0** National Semifinalist (1.65 Lakh+ participants)
  - **1st Place – XcelCrowd SprintOne** Engineering Challenge
  - **Runner-up – YUVA 2025**
  - **NPTEL Elite+Gold & Elite+Silver**, **AWS Academy Graduate** certifications
- **Journey Timeline & Education**: Interactive experience timeline for DBS Tech and Vasavi College of Engineering.
- **Curriculum Vitae Modal**: Complete in-browser printable/downloadable resume viewer.
- **Interactive Contact Form & 1-Click Clipboard**: Instant copy for Email and Phone numbers with toast confirmations and celebratory confetti.

## 🚀 Getting Started

### 1. Run Locally
```bash
# Navigate to project directory
cd sriya-portfolio

# Install dependencies (already installed)
npm install

# Start development server
npm run dev
```

### 2. Build for Production
```bash
npm run build
```

### 3. Deploy to Vercel (1-Click)
```bash
npx vercel
```
Or connect your GitHub repository directly to [Vercel](https://vercel.com) — it will automatically detect Vite and deploy in seconds!
